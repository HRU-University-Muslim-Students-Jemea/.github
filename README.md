**Serving Muslim students through faith, knowledge, unity, and community.**

Haramaya University Muslim Students' Jama'a (HUMSJ) is a Muslim student community dedicated to promoting Islamic values, strengthening brotherhood and sisterhood, and supporting the spiritual, educational, and social development of Muslim students across its campuses.

## About This Repository

This repository contains organization-wide GitHub community health files and default configurations used across HUMSJ repositories.

### What You'll Find Here

* **Community guidelines** — expectations for respectful and constructive participation.
* **Contribution guidelines** — instructions for contributing to HUMSJ projects.
* **Issue templates** — standardized templates for reporting issues and proposing improvements.
* **Pull request templates** — guidance for submitting code and documentation changes.
* **Organization profile** — public information about HUMSJ and its technology initiatives.

## Our Principles

* **Faith:** Upholding Islamic values and principles.
* **Knowledge:** Encouraging learning, education, and innovation.
* **Unity:** Building a strong and supportive Muslim student community.
* **Service:** Using our skills and resources to benefit students and the wider community.
* **Integrity:** Maintaining accountability, respect, and responsibility in our work.

## Contributing

We welcome constructive contributions to HUMSJ's digital initiatives. Please review the relevant contribution guidelines in each repository before submitting changes.

All contributors are expected to communicate respectfully and help maintain a welcoming, collaborative environment.
